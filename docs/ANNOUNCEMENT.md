## Long version (launch post)

> **Day Reminders is live.**
>
> Built this because my reminders kept scattering across five different places — Outlook tasks, Notion, Teams DMs to myself, the back of my hand. So now there's a tab inside Teams. You add what you need to remember; the bot pings you in chat before each one. That's the whole thing.
>
> **What it does today:**
>
> - Reminders with a date, time, client (autocompletes from your past), and notes. Tags via `#hashtags` in the title.
> - A card lands in your Day Reminders chat when each one fires — Mark done, or Snooze 15m / 1h / Tomorrow.
> - Quick-add from any Teams chat: `...` under the message box → Day Reminders → type → done. Use it when you're mid-conversation with someone and remember something.
> - Slash commands in the bot chat too: `/add 5pm tomorrow #qc Review batch 14`. Dates can be `tomorrow`, `mon`, `6/20` — whatever.
> - Group by client or tag, filter to one project, see your whole week at a glance to figure out if you're free or bombarded.
> - End-of-day "are you done?" check-in at a time you pick.
>
> **From the feedback already shipped:**
>
> - Calendar / week view — there.
> - Client column — there. Shows up as `[Client] Title` on every reminder and in the card.
> - Auto-rollover of stuff you didn't finish — there, with an *overdue Nd* badge so you can see what's been sitting around.
> - Free-form details / notes per reminder — there.
>
> **Coming next (v1.5):** sharing. Assign reminders to teammates; set per-tag default share lists so `#QC` auto-shares with the QC team without picking recipients each time.
>
> **How to start:** alarm-clock icon in your Teams left rail. Two tabs at the top — Reminders (the UI) and Chat (where the bot pings you). If you don't see the icon, ping me — sideload propagation can be slow.
>
> Try it now. The `+ Templates` pill at the top has some starter reminders if you want to see how it feels with data in it.
>
> Bugs, requests, "this is annoying" feedback → drop them in this channel or DM me. I'm iterating on this fast.
>
> — Josh
