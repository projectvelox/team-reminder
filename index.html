Welcome to Day Reminders

  1. Type a task in the box above and press Add. Pick a date, time, client, and tags from the boxes next to it.
  2. Set a Client for engagements you bill — the field autocompletes from past ones and shows on every reminder.
  3. Use the Tags picker to group related work (work, personal, urgent…). Tags autocomplete from ones you've used before.
  4. Click + Notes below to attach context, links, or a checklist of sub-steps.
  5. Open the Chat tab to get a ping before each reminder. The bot shows buttons — no need to remember any commands.

Quick guide
  • Tags: use the Tags picker below the add row. Type and press Enter to add a chip; autocompletes from past tags. Click any tag chip on a row to filter; Esc clears.
  • Client: set a client per reminder; autocompletes from past ones. Click the client chip on a row to filter to it; click again to clear.
  • Checklist: open the ⋯ menu on a row to add sub-tasks. Each row with sub-tasks shows a "2/5" chip; expand it on the row to tick items off without opening the dialog.
  • Repeat: in the ⋯ menu, set Repeat to Daily, Weekdays, or Weekly. Marking done advances to the next occurrence — recurring items never go overdue.
  • Auto-roll: undone one-off reminders carry forward to today (up to 30 days) with an overdue Nd badge.
  • Edit inline: click a title, date, time, or notes on any row to change it. Enter saves, Esc cancels.
  • Reorder: drag the ☰ handle (within Anytime today, tag, and priority sections).
  • Shortcuts: / add, f search, g group, v view, ? toggle this guide, Esc clear filters.

Settings

The bot will send an "Are you done?" card to your chat at this time on workdays.

No proactive cards or activity-feed pings between these times. Set both to leave blank to disable. Reminders that come due during quiet hours fire on the first tick after the window ends.

"Match Teams" follows whatever theme you have in Teams. The others lock the appearance regardless of the host.

What's new

  • v1.5.1 — non-developer friendliness pass
    • Checklist (sub-tasks): a reminder can now hold a list of sub-steps with real checkboxes. Open the ⋯ menu, type each sub-task and press Enter. Each row with sub-tasks gets a "2/5" chip and a chevron to expand the checklist inline — tick boxes without opening a dialog.
    • Tag picker: the add form now has a proper Tags box next to Client. Type and Enter to add a chip; autocompletes from your past tags. Typing #tag inside the title still works for power users.
    • Lead time as a dropdown: "Right at the time / 5 / 10 / 15 / 30 min / 1 hr / 2 hr / Custom" instead of a number field. Applies to both your default in Settings and the per-reminder override.
    • Bot replies with buttons: when you message the bot freely or open /help, you get an action card (Add a reminder, What's on my list?, Mark something done, Show me how) instead of a wall of slash-command syntax.
    • Cleaner templates: built-in templates no longer have #work visible in the title — the tag shows as a chip below the name, matching how your own reminders look.
    • Smaller copy fixes: Timed filter pill is now Scheduled; + Details is now + Notes; the empty-list screen shows clean example reminders without hash-tag syntax.
  • v1.5.0 — usability bundle (QOL audit)
    • Search now covers your notes: typing in the search box matches title, tags, client, AND description. Same for the bot's /done substring command.
    • Recurring reminders: open a reminder's options dialog and set Repeat to Daily, Weekdays (Mon–Fri), or Weekly. Recurring items auto-advance to the next occurrence when you mark them done. They never become overdue.
    • Quiet hours: in Settings, set a quiet window (e.g. 20:00 to 07:00). No proactive cards or activity-feed pings during those hours. Reminders that come due inside the window fire at the first tick after it ends.
    • Save as template: any reminder can now become a reusable template — open its options dialog and click Save as template. Personal templates show above the built-in ones, with delete buttons.
    • More reschedule options on the proactive card: +3 days and Next Mon alongside the existing Snooze 15m / 1h / Tomorrow.
    • Bulk actions are now one round-trip: Mark all done, bulk done, and bulk priority no longer loop one PATCH per reminder.
  • v1.4.6
    • Performance: rows without a description no longer render an empty details block (saves ~100+ DOM nodes per render in typical use). To add or edit a description on an existing reminder, click the ⋯ menu — the row options dialog now has a Details textarea.
    • Performance: client autocomplete datalist now skips DOM rebuild when the unique client set hasn't changed since last render.
    • Performance: skip the redundant post-API re-render after most inline edits (title, time, date, description, client, done, priority, snooze, lead time). The optimistic render already showed the new state; the server response usually matches.
    • Performance: memoized colorForTag / colorForClient so repeat lookups are O(1).
    • Plus a separate Azure Logic App keep-warm ping every 5 min (PH hours) so the Function App doesn't cold-start when no-one's used it for a while.
